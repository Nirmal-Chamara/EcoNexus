# EcoNexus evidence pack

This folder is the handover structure for Phase F9. Replace the capture slots with real device evidence after running [mobile-demo-script.md](../mobile-demo-script.md).

## Contents

- [test-results.md](./test-results.md) — latest automated validation summary and reproducible commands.
- [commit-log.md](./commit-log.md) — commit-history snapshot and final-commit capture command.
- [screenshots/README.md](./screenshots/README.md) — required Android/iOS screenshot names and capture notes.
- [figma-vs-app/README.md](./figma-vs-app/README.md) — side-by-side comparison checklist and naming convention.

## Final submission checklist

- [ ] Add onboarding, login, registration, pending, role-tab, profile, admin queue, approval, suspension, and forced-logout screenshots.
- [ ] Add at least one Android device record and, if available, one iOS device record.
- [ ] Add the final commit hash after the F9 changes are committed.
- [ ] Add Figma reference exports or links and matching app captures.
- [ ] Record any known backend/manual acceptance limitation.

Do not place real passwords, refresh tokens, private API keys, or production user data in this folder.
